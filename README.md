# Rerararaeaea

Chcę odtworzyć interfejs istniejącego projektu 1:1.

Źródłem referencyjnym jest mój istniejący projekt znajdujący się w tym repozytorium GitHub:
https://github.com/ghoters/pixel-perfect-echo-245

Potraktuj ten projekt jako SOURCE OF TRUTH dla warstwy wizualnej.

Twoim zadaniem jest odtworzyć jego frontend możliwie dokładnie, zachowując:

identyczny layout i strukturę stron,

identyczne rozmieszczenie elementów,

identyczne odstępy, marginesy i paddingi,

identyczne szerokości i wysokości elementów,

identyczne fonty, rozmiary tekstu, grubości i line-height,

identyczne kolory, obramowania, cienie i promienie zaokrągleń,

identyczne przyciski, inputy, karty, menu i pozostałe komponenty,

identyczne ikony i ich rozmiary,

identyczne zachowanie responsive na desktopie, tablecie i mobile,

identyczne stany hover, focus, active, disabled oraz pozostałe stany interaktywne,

identyczne animacje i przejścia, jeśli występują.

Nie twórz nowego designu i nie upraszczaj istniejącego interfejsu.

Najpierw przeanalizuj strukturę istniejącego projektu, jego komponenty, style i zależności. Następnie odtwórz wizualną strukturę w tym projekcie.

WAŻNE:

nie zmieniaj wyglądu według własnego uznania,

nie zastępuj istniejących elementów „podobnymi” rozwiązaniami, jeśli można odtworzyć oryginał,

nie usuwaj elementów tylko dlatego, że wydają się niepotrzebne,

zachowaj proporcje i spacing,

jeśli jakaś rzecz nie jest jasna, najpierw przeanalizuj istniejący kod zamiast zgadywać.

Celem jest pixel-perfect recreation istniejącego interfejsu, a nie stworzenie podobnego projektu.

Po wykonaniu zmian sprawdź każdą stronę i popraw różnice wizualne względem projektu źródłowego.
